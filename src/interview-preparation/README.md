# 面试准备

这里不堆“所有资料”，而是先给复习顺序、项目表达和追问路径。

## 建议顺序

1. 先读 [怎么准备这场面试](./interview-prep-overview.html)，建立主线。
2. 按 [四周复习计划](./interview-prep-four-week-plan.html) 安排节奏。
3. 投递前打磨 [简历](./interview-prep-resume.html) 和 [自我介绍](./interview-prep-self-intro.html)。
4. 用 [STAR 项目模板](./interview-prep-project-star.html) 把 2-3 个项目故事写透。
5. 按 [高频追问树](./interview-prep-followup-trees.html) 把主干题扩到第 3-4 层。
6. 临场前过一遍 [容易答飘的点](./interview-prep-common-traps.html)，备好 [反问](./interview-prep-questions-to-ask.html) 和 [紧张兜底](./interview-prep-nerves.html)。
7. 再回到 [Java](../java/) 与 [数据库](../database/) 补盲区。

## 复习目标

- 每道题先讲解决什么问题，再讲关键流程和边界。
- 尽量把答案落回真实项目里的配置、风险和排障。
- 对来源有冲突的知识点，优先整理自己的判断而不是照搬。
