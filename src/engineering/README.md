# 工程与交付

这一栏讲的是"写代码之外、但决定项目能不能验收"的那部分能力：把客户口述的诉求变成可验证的需求、把设计写成别人能接手改的文档、让前后端联调少返工、把测试写在真会出错的地方、交付一套运维敢接手的材料。

定制项目里，技术方案的差距通常不大，**差距在过程和交付**——需求没对齐、文档没落地、验收没证据，最后都在现场返工。
